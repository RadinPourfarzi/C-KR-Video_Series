# Learning C Through K&R

This repository contains source code, slides, notes, and exercises for my video series walking through *The C Programming Language* by Brian Kernighan and Dennis Ritchie.

The goal of the series is not to replace the book, but instead to provide beginner-friendly supplementary explanations and examples.
