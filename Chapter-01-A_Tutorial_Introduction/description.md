# YouTube Description Draft — Chapter 1: A Tutorial Introduction

In this video, we work through Chapter 1 of *The C Programming Language* by Kernighan and Ritchie: **A Tutorial Introduction**.

The goal is not mastery yet. Chapter 1 is a fast tour of C: enough to start writing small programs and to recognize how the major pieces of the language fit together.

## Topics covered

- What a C source file is
- Compiling and running a C program
- `#include <stdio.h>`, `main`, `printf`, and `return`
- Variables, assignment, arithmetic, and loops
- The Fahrenheit/Celsius temperature-table program
- Character input with `getchar`, `putchar`, and `EOF`
- Simple arrays
- A short preview of a larger Chapter 1 assignment

## Exercises

1. Rewrite the temperature-table program using a `for` loop.
2. Modify a character-input program to count lines, blanks, tabs, or a chosen character.
3. Try reconstructing the word-counting program.
4. For a harder challenge, study or recreate the longest-line program.
